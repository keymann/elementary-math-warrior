# 수학 서바이버 — 블랙박스 측정표

> 측정일 2026-08-06 · 대상 https://mathsurvivorbh.netlify.app/ · 학년 4학년 고정
> 방법: Playwright 실입력(키보드)으로 플레이하며 **화면에 표시되는 값(HUD·오버레이 텍스트)만** 0.4초 간격 샘플링.
> 원작 소스는 열람·복원하지 않음(난독화된 보호 코드). 아래는 전부 플레이어가 화면에서 볼 수 있는 정보.

---

## 0. 측정 환경 / 한계

| 항목 | 내용 |
|---|---|
| 조작 봇 | 3.5초마다 90° 회전하는 직선 카이팅. **적 위치를 모르는 블라인드 조작** |
| 문제 응답 | 자동 솔버(사칙연산식·등차수열·단답 문장제 추론). 미해결 문항은 0번 선택 |
| 도달 구간 | **최대 1분 31초** — 3·6·10분 보스 구간은 미도달 |
| 신뢰도 | 무기별 n=1. 사망 시점은 봇 조작 미숙 영향이 지배적 → **무기 우열 근거로 쓸 수 없음** |

**중요**: 이 표의 값은 "초반 1분 구간의 페이싱"에 한해 유효하다. 후반 데이터가 필요하면 사람이 직접 플레이하며 같은 항목을 기록해야 한다.

## 3. 타이머 정지 규칙 (실측 확인)

- **퀴즈 오버레이가 열려 있는 동안 게임 타이머가 멈춘다.**
  - 근거: 실시간 25초 경과 구간에서 게임 타이머는 23초만 감소(퀴즈 2초 점유분 제외)
  - 문항을 33초간 붙잡아 둔 케이스에서도 타이머·적 이동 모두 정지
- 강화 카드 선택 화면도 동일하게 정지
- **문제 푸는 시간이 생존 시간을 깎지 않는다** → 학습 도구로서 핵심적인 결정. 클론에서 반드시 계승

## 4. 레벨업 · XP 페이싱

### 4판 레벨업 시점 (게임 시각)

| 무기 | Lv.2 | Lv.3 | Lv.4 | Lv.5 | 비고 |
|---|---|---|---|---|---|
| 🖊️ 연필 미사일 | 09:39 (21초) | 09:22 (38초) | 09:10 (50초) | – | 1:31 사망 |
| 🎵 리코더 검격 | 09:23 (37초) | – | – | – | 0:39 사망 |
| ⚽ 피구공 던지기 | 09:32 (28초) | 09:15 (45초) | 09:07 (53초) | **09:06 (54초)** | 1:02 시점 생존 |
| 🖍️ 크레파스 산탄 | 09:39 (21초) | 09:28 (32초) | – | – | 0:39 사망 |

- **Lv.1→2 도달: 21~37초**
- 레벨 간격이 점점 짧아짐 → XP 요구량 증가보다 **처치 속도 증가가 더 가파름**
- **Lv.4→5가 1초 만에** 발생(피구공 런). 직전 09:07에 "맵 전체 자석" 발동 → 흩어진 보석 일괄 회수로 **즉시 레벨업**
  → 자석 아이템은 사실상 "레벨 1~2개 즉시 지급" 수준의 강력한 보상. 클론 밸런싱 시 주의

### 초반 1분 처치 수

| 무기 | 처치 수 | 시점 |
|---|---|---|
| 연필 미사일 | 60 | 1:31 |

> 리코더(10킬)와 크레파스(31킬)가 같은 39초에 사망 — 관통형 무기는 **블라인드 조작에서 명중률이 급락**. 사람 조작에서는 결과가 달라질 가능성이 높다.

## 5. 강화 카드 (레벨업 보상)

- **항상 3택**. 구성은 [신규 무기 / 보유 무기 레벨업 / 신규 패시브]가 섞여 나옴
- 카드에 **각성 짝꿍 힌트가 상시 표기**됨 → 진화 경로를 플레이어가 추측할 필요 없음

| 패시브 | 효과 | 각성 재료로 쓰이는 무기 |

| 👟 달리기 운동화 | 이동 속도 **+8%** | 피구공 던지기 Lv.5 |

> 패시브 1개가 **복수 무기의 각성 재료로 공유**된다(수학책·힘의 장갑·하트 배지 각 2종). 빌드 분기를 만들면서도 패시브 가짓수를 늘리지 않는 효율적 설계.

## 6. 퀴즈 (4학년 기준)

### 출제 빈도
- 레벨업 1회 = 문제 1개. 별 몬스터 처치 시 보너스 문제 추가
- **초반 1분에 3~7문항** 노출 (피구공 런 62초에 7문항)
- 오답이어도 게임은 계속되나 **강화 카드는 받지 못함** → 정답률 0%였던 첫 런은 Lv.2에서 21초 만에 사망

### 관찰된 문항 유형 (4학년 1학기)

| 유형 | 예시 형태 | 빈도 |
|---|---|---|
| (세 자리 수) × (두 자리 수) | `310 × 48 = ?` | 높음 |
| (세 자리 수) ÷ (두 자리 수) | `207 ÷ 23 = ?` | 높음 |
| 규칙 찾기(등차수열) | `13, 21, 29, 37, ▢` | 중간 |
| 도형의 이동(밀기·뒤집기·돌리기) | "거울에 비친 모습처럼 옮기기는?" | 중간 |
| 자료와 그래프 | "막대 한 칸 5명, 7칸이면?" | 낮음 |

- **보기 4지선다 고정**, 오답 보기는 자릿수 실수·연산 혼동형(예: 35에 대해 38·45·25)
- 계산형이 다수, 개념·용어형(도형 이동)이 섞임

### 결과 화면 칭호 (정답률 연동 확인)

| 정답률 | 칭호 |
|---|---|
| 100% | 📚 지혜로운 현자 |
| 67% | 🌱 새싹 용사 |
| 0% | 🌱 새싹 용사 |

- 별점은 4판 모두 `☆☆☆`(0/3) — **생존 시간 기반**으로 추정(1분 31초로는 미달)

## 8. 클론 설계에 직접 반영할 결론

1. **퀴즈 중 타이머 정지는 필수** — 학습과 게임의 이해충돌을 없애는 단 하나의 규칙
2. **첫 이벤트를 13초 안에** — 초반 공백 없이 즉시 보상 루프 진입
3. **자석류 보상은 레벨 1~2개 즉시 지급급 위력** — 밸런스 시뮬레이터에서 별도로 상한 검증
4. **오답 페널티는 카드 미획득뿐** — 게임 오버로 직결되진 않지만, 초반 오답이 누적되면 사실상 사망(정답률 0% 런은 21초 생존). 클론에서는 **오답 시에도 하위 보상(작은 강화)을 주는 방안**을 검토할 가치가 있음
5. **각성 짝꿍 힌트 상시 노출** — 초등 대상에서 진화 조건을 숨기지 않는 판단은 옳다
6. 카드 3택 구성 비율(신규 무기/레벨업/패시브)을 우리 시뮬레이터의 튜닝 파라미터로 노출할 것
